# 欢迎来到项目实战

项目实战把讲义里的概念压进真实动作里。每个项目都要求你留下证据：命令、输出、diff、截图、session 名称或简短复盘。

| 项目 | 目标 | 产出 |
| --- | --- | --- |
| P01 | 安装 Pi 并分析一个仓库 | 仓库分析笔记 |
| P02 | 给项目添加最小规则 | `AGENTS.md` |
| P03 | 管理长任务和分支 | session 工作记录 |
| P04 | 写 Prompt Template 和 Skill | `.pi/prompts/`、`.pi/skills/` |
| P05 | 写一个小 Extension | `.pi/extensions/` |
| P06 | 组装完整 Harness | 评分表和复盘 |

## 做项目的原则

- 不追求一次性完美，追求可复现。
- 每个项目只引入一类新机制。
- 每次结束都写下“我验证了什么，还有什么没验证”。

## 开始

从 [P01. 安装 Pi 并完成第一次仓库分析](/projects/01-first-repo-analysis) 开始。
