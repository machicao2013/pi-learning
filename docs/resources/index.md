# 中文资料库

资料库把教程中的方法压缩成可复制材料。它不是概念复述，而是回答两个问题：

- 我现在应该先放哪些文件进项目？
- 这些文件分别解决什么失败模式？

## 推荐最小组合

| 文件 | 解决的问题 |
| --- | --- |
| `AGENTS.md` | 不再重复解释项目规则 |
| `.pi/prompts/review.md` | 固定高频审查提示 |
| `.pi/skills/handoff/SKILL.md` | 固定跨会话交接流程 |
| `.pi/extensions/project-status.ts` | 把项目状态变成可调用工具 |
